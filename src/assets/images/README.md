# Images

Use this folder for real or licensed image assets that support story sections.

## Expected Files

- `founder-portrait.*` or `founder-signature.*`
- `hospitality-atmosphere-*.jpg`
- `service-scene-*.jpg`

## Usage Targets

- Founder visuals for `FounderNote` and About page sections.
- Atmosphere support images for product and vision storytelling sections.

## Acceptance Rules

- Use authentic or licensed imagery only.
- Keep visuals premium and hospitality-first.
- Do not add fake logos, fake venues, fake testimonials, or implied customer proof.
- Prefer filenames that clearly map to section usage.
