Use this folder for product renders and diagram graphics referenced by placeholder blocks.

- `hero-menu-render.*`

- `object-closeup-02.*`

## Usage Targets

- Hero visual region in `HeroManifesto`.
- Object media region in `ObjectReveal`.
- Diagram placeholder callouts in CategoryGap, ServiceFit, and FutureLayer.

## Acceptance Rules

- Product must read as a paper-like premium menu object.
- Keep displays monochrome/text-first and avoid tablet UI chrome.
- Keep roadmap and diagram language stage-honest.
- Do not introduce visuals that imply mature traction or unbuilt capabilities.
