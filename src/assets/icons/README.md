# Icons

Use this folder for lightweight icon assets used in feature or capability blocks.

## Expected Files

- `feature-language-switch.svg`
- `feature-menu-states.svg`
- `feature-low-light.svg`
- `feature-staff-control.svg`

## Usage Targets

- Capability and feature cards on Home, Product, and Vision.
- Optional support visuals where icon reinforcement improves scannability.

## Acceptance Rules

- Keep stroke weight and visual rhythm consistent.
- Keep style restrained; avoid playful startup icon language.
- Do not use iconography that suggests guest-side ordering or tablet-first interaction.
